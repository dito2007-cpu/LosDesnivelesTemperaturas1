LOS DESNIVELES — versión HTML

1. Abre index.html en Chrome.
2. Los datos se guardan automáticamente en localStorage del navegador.
3. Puedes añadir la página a la pantalla de inicio del móvil para usarla como una app.
4. Los registros sobreviven al cierre de la página/navegador mientras no se borren los datos del sitio.
5. Exporta CSV para Excel. El botón PDF usa la impresión del navegador y permite "Guardar como PDF".

IMPORTANTE:
- Esta versión guarda los datos SOLO en ese móvil/navegador. Si borras los datos del navegador o cambias de móvil, no estarán disponibles.
- Para una versión con copia en la nube y acceso desde varios móviles habría que añadir una base de datos/servidor.
- Los límites iniciales son 8 °C para refrigeración y -18 °C para congelación y son editables desde Configuración.
